# EduPath UI

A modern, full-stack educational platform UI built with React, TypeScript, and Tailwind CSS. EduPath provides a comprehensive solution for managing educational pathways with an intuitive dashboard, data visualization, and powerful form management capabilities.

## Features

- **Modern UI Components**: Built with Tailwind CSS for accessible, responsive interfaces
- **Real-time Data Management**: Powered by TanStack React Query for efficient server state management
- **Advanced Forms**: Form validation and management using React Hook Form and Zod
- **Data Visualization**: Interactive charts and analytics using Recharts
- **File Handling**: Excel export/import capabilities with XLSX and PDF generation
- **Dark Mode Support**: Theme switching with next-themes
- **Responsive Design**: Mobile-first approach with full responsiveness
- **Type Safety**: Comprehensive TypeScript support for robust development
- **Command Palette**: Fast navigation with CMDk command palette

## Installation

### Prerequisites
- Node.js 18+ 
- npm or yarn
- PostgreSQL database
